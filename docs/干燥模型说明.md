# 干燥计算模型说明

本文件说明后端的两级物理计算与两次称重之间的含水率估计方法，包括出处、
误差来源，以及该估计对“阶段切换时刻”方向性的影响。所有计算都在后端完成，
页面只负责编辑与展示。

## 1. 干湿球温度 → 相对湿度（RH）

采用世界气象组织《地面仪器与观测方法指南》（CIMO Guide, WMO-No. 8）中的
通风干湿表（阿斯曼）公式：

```
e  = e_s(Tw) − A·p·(Td − Tw)
RH = e / e_s(Td)
A  = 6.62×10⁻⁴ /°C（通风、液面、0°C 以上）
p  = 1013.25 hPa（车间按标准海平面气压，不做海拔修正）
```

饱和水汽压用 Buck（1981，水面）Magnus 式：

```
e_s(T) = 6.112 · exp(17.62 T / (243.12 + T))   [hPa, °C]
```

实现见 `server/src/domain/physics.ts`。

误差来源：

- 气压取标准值。海拔每升高约 100 m，气压约降 12 hPa，对 RH 的影响约零点几个
  百分点，车间场景可忽略；若以后接海拔数据可改为实测气压。
- A 系数对应“强制通风”干湿表。无风静置的湿球会偏高，算出的 RH 偏湿（偏高）。
- 温度传感器自身误差按 ±0.2°C 计，在常见干湿温差下 RH 误差约 ±1~2 个百分点。

## 2. 相对湿度 → 平衡含水率（EMC）

采用 Simpson (1973) 的 Hailwood–Horrobin 吸湿方程（吸附系数，摄氏温度版），
出处：

- Simpson, W.T. (1973). *Predicting Equilibrium Moisture Content of Wood*.
  Wood and Fiber, 5(2): 148–163.
- USDA Forest Service, *Wood Handbook: Wood as an Engineering Material*,
  第 13 章 Table 13-4（原表给华氏温度系数；本实现使用该方程的摄氏温度变换
  系数集，即 K、K1 均含温度二次项，也是国内木材干燥教材通行写法）。

令 T 为摄氏温度、h = RH/100：

```
W  = 349 + 1.29T + 0.0135T²
K  = 0.805 + 7.36×10⁻⁴T − 2.73×10⁻⁷T²
K1 = 6.27 − 0.00938T − 3.03×10⁻⁴T²
K2 = 1.91 + 0.0407T − 2.93×10⁻⁴T²

M  = (1800/W) · [ Kh/(1−Kh)
                 + (K1·Kh + 2·K1·K2·K²h²)
                   / (1 + K1·Kh + K1·K2·K²h²) ]      [%]
```

参考值校验（实现锁定值，Vitest 断言）：

| 条件 | 本实现 | 给定参考 |
|---|---|---|
| 20°C / RH 65% | **12.00%** | 约 12.0% |
| 60°C / RH 80% | **13.56%** | 约 13.6%（±0.3） |

注意：这组系数是**吸附（sorption/adsorption）**平衡，即木材从较干状态向环境
回潮时的平衡。窑内实际是**解吸（desorption）**过程，同温湿度下解吸平衡含水率
系统性地比吸附值高（木材含水率的“滞后回线”，高含水率段差别几个百分点，
接近终了时较小）。我们用吸附值，是因为它是 Wood Handbook 唯一给出全套摄氏
系数、且两个参考值都落在公差内的业界通行形式；代价是估计出的 Me **偏干**，
见第 4 节的方向分析。如要更贴近解吸，可改用解吸系数或对 Me 乘滞后修正系数，
这属于后续标定项。

## 3. 样板含水率（绝干基）

```
m_绝干 = m_初称 / (1 + MC_初)
MC(t)  = m(t) / m_绝干 − 1
```

参考值校验：初称 5000 g、初始 MC 60% → 绝干质量 3125 g；称得 4062.5 g 时
MC = 4062.5/3125 − 1 = **30.0%**。

称重是整条轨迹的**绝对锚点**：任何模型估计在收到称重的瞬间都被钉到实测值，
模型误差不会无限累积。

## 4. 两次称重之间的含水率估计（关键选型）

### 选定方法：一阶松弛（集总参数）干燥模型 + 称重锚点

```
M(t+Δt) = Me + (M(t) − Me) · exp(−k·Δt)
```

- Me：由“最近一次干湿球读数”按第 1、2 节实时算出的平衡含水率；
- k：干燥速率常数（1/小时），批次开跑时可带，缺省 0.05/h；
- 收到干湿球读数：只更新 Me，M 连续不变；
- 收到称重：M 直接钉到实测 MC（第 3 节）；
- 模型在两条读数之间解析地越过阶段阈值时，用解析反解求越界时刻，秒级取整。

### 为什么不选“保持上次值”

“保持上次值”不依赖任何参数，最稳，但在两次称重（现场约 2 小时一次）之间
含水率是一条水平线，**阶段切换必然滞后**：样板已经干透，也要等下一次称重
才能发现。橡木开裂事故的背景正是阶段控制粗糙，滞后意味着木料在偏湿/偏热
条件下多待一个称重周期，方向是危险的。

松弛模型用当前温湿度给出一条单调逼近 Me 的曲线，切换在“越过阈值的估计时刻”
发生，不需要等下一次称重，更及时；每次称重又把估计拉回实测，防止漂移累积。
这是干燥模拟中最常用的最简动力模型（单集总参数、指数趋近平衡），参数只有
一个 k，可按厚度/树种给经验值，未来也容易换成更细的扩散模型而不动接口。

### 误差来源

1. **模型结构误差**：真实木料有厚度方向的含水率梯度，表层先干、心层后干，
   集总参数模型只描述“样板平均含水率”的等效行为，初期可能偏快、后期偏慢。
2. **k 的取值**：k 受树种、厚度、风速、初含水率影响。给高了（干得太快）
   会提前切换，给低了会推后。缺省 0.05/h 是保守的中等量级，工艺员可在开跑
   参数中覆盖；连续两三次称重即可用实测反推 k 做标定。
3. **Me 偏差**：第 2 节说明吸附系数在解吸场景下偏干；RH 误差（第 1 节）经
   EMC 方程放大，60°C 附近 RH 偏 2 个百分点约使 Me 偏 0.2~0.3 个百分点。
4. **称重误差/样板代表性**：样板与整批料的干燥速率不完全一致，这是所有
   样板法的固有误差，锚点本身也可能有几克称量误差。
5. **读数间隔内温湿度按“最后一次读数”恒定处理**：区间内实际气候调节的变化
   不参与积分，间隔越长近似越粗；现场两小时一条读数，影响有限。

### 它让切换提前还是推后？

相对“真实样板含水率越过阈值的时刻”，偏差方向取决于上述各项的合力，
但系统性倾向可以讲清：

- 在**没有称重校正的长区间**、且窑况稳定时，Me 因吸附/解吸滞后而**偏干**，
  模型朝一个偏低的目标下降，**估计的 MC 偏低 → 切换提前**。
- k 给大了同样提前；k 给小了推后。
- 每次称重若显示模型超前（实测 MC 高于估计），锚点会把曲线拉回，后续切换
  时刻随之被纠正——重放是确定性的，历史切换时刻也会以该称重时刻为界重算，
  保证最终时间轴与“按时序上报”完全一致。

安全含义：提前进入更高温阶段对防开裂不利，因此两个缓解措施已内置：
① 称重锚点频繁校正（2h 一次）；② k 缺省取偏保守值。建议运行一段时间后
用实际称重数据回归各树种/厚度的 k 与 Me 修正系数，再逐步收紧。

## 5. 确定性与一致性保证

窑状态（当前阶段、切换时间轴、曲线）**不单独落库**，随时由

```
批次参数（含绑定版本的有效基准） + 该窑全部读数
```

经 `replay()` 重放得到。读数在重放前按 `(recorded_at 升序, record_no 升序)`
规范排序，与上报先后无关；`record_no` 全局主键拒绝重复。因此：

- 乱序上报、晚到补录：最终结果 = 按时刻顺序上报的结果（切换时刻逐秒相同）；
- 重复记录编号：数据库唯一约束拒收（409），已存内容不变；
- 服务重启：从读数与批次表重放，不丢不重。

阶段进入条件判定为**严格小于**（MC < 阈值才切换），等于阈值时停在原阶段。
